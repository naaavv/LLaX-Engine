[ PHASE 2: 2D/3D RENDERING PIPELINE ] ✅ COMPLETE
================================================================================
[x] 1. Graphics Context abstraction
       - GraphicsContext base class (virtual Init, SwapBuffers)           Engine/src/Renderer/GraphicsContext.h
       - OpenGLContext implementation (make context current, init GLAD)   Engine/src/Platform/OpenGL/OpenGLContext.h/.cpp
       - Window refactored: owns Scope<GraphicsContext>, delegates Init() & SwapBuffers()
       - OpenGLContext logs GPU info via LLAX_CORE_INFO (not raw cout)

[x] 2. Buffer Abstraction:
       - VertexBuffer (static & dynamic data uploads, GL_STATIC_DRAW / GL_DYNAMIC_DRAW)
       - IndexBuffer / ElementBuffer
       - BufferElement (name, type, size, offset, normalized)
       - BufferLayout (stride, list of BufferElements, iterator)
       - VertexArray (wraps VAO — binds VBO + IBO + layout)
       🎯 MILESTONE: Draw your first colored triangle! ✅ COMPLETE

[x] 3. Shader System:
       - Shader class: compile Vertex & Fragment GLSL from file or string
       - Uniform upload helpers (SetInt, SetIntArray, SetFloat, SetFloat2, SetFloat3, SetFloat4, SetMat4)
       - ShaderLibrary: load, cache, and retrieve shaders by name
       - Assets/shaders/ folder for .glsl files with multi-stage preprocessor

[x] 4. Camera System:
       - OrthographicCamera (glm::ortho projection, view matrix, VP matrix)
       - OrthographicCameraController (WASD pan, scroll-wheel zoom, aspect ratio, event dispatch)
       - PerspectiveCamera & 3D Editor Camera (orbit, pan, zoom, free-fly) [later]

[x] 5. Texture System:
       - Texture2D class using stb_image (RGBA8, RGB8, R8)
       - Texture filtering (Linear, Nearest) & wrapping (Repeat, Clamp)
       - Bind/Unbind, 32-slot management
       - Dynamic data upload (SetData) for solid color fallbacks
       - SubTexture2D / SpriteSheet atlas coordinate slicing

[x] 6. 2D Batch Renderer (High-Performance Quad Renderer):
       - Renderer2D::BeginScene(camera) / EndScene() / Flush()
       - DrawQuad(position, size, color)
       - DrawQuad(position, size, texture, tilingFactor, tintColor)
       - DrawRotatedQuad(position, size, rotation, ...)
       - Batching up to 20,000 quads in a single draw call
       - Multi-texture batching (up to 32 texture slots per draw call)
       - Renderer2D::Statistics (draw calls, quad count, vertex count, index count)
       🎯 MILESTONE: 1000 quads, 1 draw call, ImGui stats panel! ✅ COMPLETE

[x] 7. Framebuffer System:
       - Framebuffer class with color attachment + depth/stencil attachment
       - Off-screen render target for game output
       - Viewport resizing & aspect ratio correction
       - Render game scene → FBO texture → ImGui::Image() in editor viewport
       🎯 MILESTONE: See your game running inside an ImGui panel! ✅ COMPLETE
